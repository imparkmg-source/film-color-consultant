# 인테리어필름 컬러 상담소

붙박이장, 싱크대, 방문, 중문, 몰딩·걸레받이, 신발장 등 시공 부위를 고르면 요즘 고객들이 가장 많이 선택하는 **스테디셀러 컬러 TOP 10**을 보여주고, 각 컬러마다

- 질감 확대 미리보기 (무광/우드그레인/하이그로시/메탈/마블 질감 시뮬레이션)
- 3D 시공 배치 시안
- 전문가 시공 Tip
- 자재비 · 인건비로 구분한 예상 견적 계산기

를 제공하는 정적 웹사이트입니다. 인테리어필름 종류가 너무 많아 선택이 어려운 비전문가 고객이, 부담 없이 원하는 컬러/디자인 방향을 좁혀갈 수 있도록 돕는 상담 보조 도구입니다.

## 실행 방법

빌드 도구 없이 순수 HTML/CSS/JS로 만들어졌습니다. 저장소를 내려받은 뒤 `index.html`을 브라우저로 열거나, 로컬 서버로 띄워서 확인하세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 폴더 구조

```
index.html        메인 페이지
css/style.css      스타일 (라이트/다크 테마 지원)
js/data.js         시공부위·컬러·팁·견적 기준 데이터
js/app.js          화면 렌더링 및 견적 계산 로직
```

## 데이터 업데이트

`js/data.js`의 `CATEGORIES`, `FILMS`, `TEXTURE_TIPS`, `CATEGORY_TIPS`, `BUDGET` 값만 수정하면 시공 부위·컬러 목록·팁·견적 기준을 손쉽게 바꿀 수 있습니다.

## 안내

- 색상·질감은 화면 표현을 위한 CSS 기반 시뮬레이션이며, 실제 필름 실물과 미세한 차이가 있을 수 있습니다. 최종 컬러는 반드시 실물 샘플북으로 확인 후 결정하세요.
- 예상 견적은 참고용이며, 실제 견적은 현장 실측 후 시공업체와 협의가 필요합니다.
