# 인테리어필름 컬러&견적 상담소

붙박이장, 싱크대, 방문, 중문, 몰딩·걸레받이, 신발장 등 시공 부위를 고르면 요즘 고객들이 가장 많이 선택하는 **스테디셀러 컬러 TOP 10**을 보여주고, 각 컬러마다 아래 내용을 제공하는 인테리어필름 컬러 상담 웹사이트입니다.

- **질감 확대 미리보기** — 무광/콘크리트/우드그레인/메탈/마블 질감을 실제 이보닥(ebodaq) 제품 이미지로 보여줍니다(불러오지 못하면 근사 색상 시뮬레이션으로 대체). "실사 이미지 참고" 버튼은 해당 제품코드로 검색된 이보닥 실제 제품 페이지로 바로 연결됩니다.
- **부위별 3D 시공 배치 시안(수량 연동)** — 붙박이장/신발장(여닫이 도어 캐비닛), 싱크대(상부장+하부장 세트), 방문(단일 도어+손잡이), 중문(유리 격자 도어), 몰딩·걸레받이(방 모서리 벽면)처럼 실제 형태에 가까운 3D 목업에 실제 제품 이미지를 입혀 보여줍니다. 사이즈 선택(자/개수/평)을 바꾸면 문짝 수·캐비닛 폭이 늘어나거나(붙박이장·싱크대·신발장), 목업이 개수만큼 나란히 반복되거나(방문·중문), 전체 크기가 커지는(몰딩) 식으로 미리보기도 함께 바뀝니다.
- **전문가 시공 Tip** — 질감별 공통 팁 + 시공 부위별 전문가 팁.
- **예상 견적 (실측 기반, 소비자 친화적 단위)** — ㎡·m를 직접 입력하는 대신, 붙박이장·싱크대·신발장은 "폭(자)", 방문·중문은 "개수", 몰딩·걸레받이는 "전용면적(평)"처럼 비전문가도 익숙한 단위를 선택하면 내부적으로 실측 면적으로 환산해 계산합니다. 로스율·부자재비·배송비가 반영된 자재비와 소요 시간/인력 기반 인건비가 자동으로 재계산되고, 방염 필름 여부도 선택할 수 있습니다. 결과는 영수증 스타일 명세(필름 자재비/부자재비/배송비/인건비 항목별 내역 + 강조형 합계 숫자)로 항상 펼쳐진 채 표시되며, 합계 아래에는 자재비·인건비 비중을 보여주는 막대그래프가 함께 나옵니다. 브랜드별(현대L&C 보닥·LX하우시스·영림임업·예림임업) 시세 참고 표도 함께 제공합니다.
- **예상 견적서 (A4 인쇄/PDF)** — 선택한 컬러의 이미지, 3D 시공 시안, 시공 팁, 화면과 동일한 영수증 스타일 견적 명세(항목별 내역 + 강조형 합계 + 비중 막대그래프), 브랜드 시세 참고표를 담은 A4 규격 견적서를 열어 브라우저 인쇄 대화상자로 인쇄하거나 PDF로 저장할 수 있습니다.

인테리어필름 종류가 너무 많아 선택이 어려운 비전문가 고객이, 부담 없이 원하는 컬러/디자인 방향을 좁혀갈 수 있도록 돕는 상담 보조 도구입니다.

헤더 우측의 버튼으로 라이트/다크 모드를 전환할 수 있으며, 선택은 브라우저에 저장되어 다음 방문 때도 유지됩니다.

## 실행 방법

빌드 도구 없이 순수 HTML/CSS/JS로 만들어졌습니다. 저장소를 내려받은 뒤 `index.html`을 브라우저로 열거나, 로컬 서버로 띄워서 확인하세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 폴더 구조

```
index.html         메인 페이지
css/style.css       스타일 (파스텔 톤, 라이트/다크 테마 지원)
js/data.js          시공부위·컬러·제품코드·팁·견적 기준 데이터
js/app.js           화면 렌더링, 3D 목업 생성, 견적 계산 로직
```

## 데이터 업데이트

`js/data.js`의 `CATEGORIES`, `FILMS`, `TEXTURE_TIPS`, `CATEGORY_TIPS`, `BUDGET`, `BRAND_GUIDE` 값만 수정하면 시공 부위·컬러 목록·제품코드·팁·견적 기준·브랜드 시세표를 손쉽게 바꿀 수 있습니다. 부위별 3D 목업 형태(캐비닛 크기, 도어 수 등)는 `CATEGORIES[].mockup` 값으로, 소비자용 사이즈 선택지(자/개수/평 등)와 실측 환산 배수는 `CATEGORIES[].sizeInput`으로, 방염 할증률·로스율 등 공통 계수는 `WASTE_RATE`/`ANCILLARY_RATE`/`FIRE_RETARDANT_MULTIPLIER`로 조절합니다.

## 데이터 출처와 실사 이미지 안내

제품명·제품코드(예: `LW116 Amber Oak`, `PNC47 Slate`)는 현대L&C "Bodaq Interior Film" 2026-2027 카탈로그의 실제 제품 정보를 바탕으로 합니다. 색상(hex)은 카탈로그 이미지를 참고해 화면 표현용으로 근사한 값이며, 실물과는 차이가 있을 수 있습니다(저작권이 있는 제품 사진 자체는 이 저장소에 포함하지 않았습니다).

"실사 이미지 참고" 팝업의 링크는 `js/data.js`의 `ebodaqLink(code)` 함수가 제품코드로 이보닥(ebodaq) 사이트를 검색하도록 만들어주므로, 각 컬러마다 실제로 일치하는 제품 페이지가 새 탭에서 열립니다.

## 견적 산출 방식과 출처

표준 필름 롤 규격(1,220mm × 50m)에 맞춰 계산합니다. 업계에서는 자재 단가를 "원/㎡"가 아니라 **"원/m"(폭 1,220mm 고정 기준)**로 매기고, 시공면의 "길이"를 구해 필요 수량을 산출합니다 — 그래서 붙박이장·싱크대·방문·중문·신발장은 실측 면적(㎡)을 1.22m 폭으로 나눠 필요한 필름 길이(m)로 환산한 뒤 m당 단가를 곱합니다. 몰딩·걸레받이는 폭이 훨씬 좁은 별도 제품이라 처음부터 길이(m) 기준으로 계산하며 이 환산을 적용하지 않습니다. 산출 공식은 `js/data.js`의 `BUDGET`에 정의되어 있습니다.

- **필요 길이** = 실측 면적(㎡) ÷ 1.22m (몰딩·걸레받이는 환산 없이 입력 길이 그대로)
- **자재비** = 필요 길이 × (1 + 로스율 12%) × m당 단가 × 방염 배수(선택 시)
- **부자재비** = 자재비 × 10% (프라이머, 사포, 마스킹테이프, 커터날 등)
- **배송비** = 15,000원 (소량 주문 기준 정액)
- **인건비** = 실측 수량 × ㎡(m)당 인건비 단가 (부위별 소요시간·최소 출장비 반영)
- 방염 필름 선택 시 자재비에 1.5~2배 할증이 적용됩니다.

**방문(문짝+문틀) 인건비는 별도로 재검토했습니다.** 문틀은 모서리와 몰딩이 많아 문짝보다 시공이 까다로운 부위인데, 실제 현장에서는 문짝+문틀 세트("한 틀")를 약 18만원(자재 6~7만원 + 인건비 약 10만원)에 시공하는 경우가 많다는 자료를 확인하고, 애초에 과하게 잡혀 있던 방문 인건비 단가를 이 수치에 맞춰 낮췄습니다.

**자재 단가는 시공업체 도매가가 아니라 소매가 기준입니다.** 일반 소비자가 필름 판매 점포나 온라인 쇼핑몰(쿠팡·SSG닷컴·다나와 등)에서 1~2.5m 정도 소량으로 구매할 때의 판매가를 기준으로 잡았습니다. 실제 보닥 브랜드 제품의 소량 판매가를 확인해보니(다나와 122cm×1m 컷 8,800~9,100원, SSG닷컴 보닥 프리미엄 단색 2.5m 28,000원=11,200원/m, 우드패턴 2.5m 40,250원=16,100원/m) 기존 산정 단가와 비슷한 수준이라 큰 틀은 유지하되, 단색·콘크리트 등급 하한을 8,000원→8,500원으로 살짝 올려 소매가에 더 가깝게 맞췄습니다. 대량 구매(도매)로 시공하면 이보다 저렴할 수 있습니다.
