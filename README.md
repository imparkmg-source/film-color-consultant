# 인테리어필름 컬러 상담소

붙박이장, 싱크대, 방문, 중문, 몰딩·걸레받이, 신발장 등 시공 부위를 고르면 요즘 고객들이 가장 많이 선택하는 **스테디셀러 컬러 TOP 10**을 보여주고, 각 컬러마다 아래 내용을 제공하는 인테리어필름 컬러 상담 웹사이트입니다.

- **질감 확대 미리보기** — 무광/우드그레인/하이그로시/메탈/마블 질감을 CSS로 시뮬레이션. "실사 이미지 참고" 버튼을 누르면 제품코드와 함께, 이보닥(ebodaq) 실제 제품 페이지로 연결되는 외부 링크 팝업이 열립니다.
- **부위별 3D 시공 배치 시안** — 붙박이장/신발장(여닫이 도어 캐비닛), 싱크대(상부장+하부장 세트), 방문(단일 도어+손잡이), 중문(유리 격자 도어), 몰딩·걸레받이(방 모서리 벽면)처럼 실제 형태에 가까운 3D 목업을 부위마다 다르게 보여줍니다.
- **전문가 시공 Tip** — 질감별 공통 팁 + 시공 부위별 전문가 팁.
- **예상 견적** — 사이즈를 바꾸면 자동으로 재계산되는 자재비·인건비·합계. 각 금액을 클릭하면 단가 × 수량 등 상세 산출 근거를 펼쳐볼 수 있습니다.
- **예상 견적서 (A4 인쇄/PDF)** — 선택한 컬러의 이미지, 3D 시공 시안, 시공 팁, 견적 내역을 담은 A4 규격 견적서를 열어 브라우저 인쇄 대화상자로 인쇄하거나 PDF로 저장할 수 있습니다.

인테리어필름 종류가 너무 많아 선택이 어려운 비전문가 고객이, 부담 없이 원하는 컬러/디자인 방향을 좁혀갈 수 있도록 돕는 상담 보조 도구입니다.

## 실행 방법

빌드 도구 없이 순수 HTML/CSS/JS로 만들어졌습니다. 저장소를 내려받은 뒤 `index.html`을 브라우저로 열거나, 로컬 서버로 띄워서 확인하세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 폴더 구조

```
index.html         메인 페이지
css/style.css       스타일 (파스텔 톤, 라이트/다크 테마 지원)
js/data.js          시공부위·컬러·제품코드·팁·견적 기준 데이터
js/app.js           화면 렌더링, 3D 목업 생성, 견적 계산 로직
```

## 데이터 업데이트

`js/data.js`의 `CATEGORIES`, `FILMS`, `TEXTURE_TIPS`, `CATEGORY_TIPS`, `BUDGET` 값만 수정하면 시공 부위·컬러 목록·제품코드·팁·견적 기준을 손쉽게 바꿀 수 있습니다. 부위별 3D 목업 형태(캐비닛 크기, 도어 수 등)는 `CATEGORIES[].mockup` 값으로 조절합니다.

## 실사 이미지 안내

이 사이트의 색상·질감 미리보기는 화면 표현을 위한 CSS 기반 시뮬레이션이며, 특정 브랜드의 실제 제품 사진을 사용하지 않았습니다(저작권 문제로 타사 제품 이미지를 무단으로 게재할 수 없어요). 대신 "실사 이미지 참고" 팝업에서 이보닥(ebodaq) 제품 페이지로 연결되는 링크를 제공합니다. 사이트 특성상 해당 페이지가 이 컬러와 100% 동일한 제품은 아닐 수 있으니 참고용으로 확인해주세요. 링크는 `js/data.js`의 `REFERENCE_SITE`에서 관리합니다.

## 안내

- 예상 견적은 참고용이며, 실제 견적은 현장 실측 후 시공업체와 협의가 필요합니다.
