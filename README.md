# 인테리어필름 컬러&견적 상담소

붙박이장, 싱크대, 방문, 중문, 몰딩·걸레받이, 신발장 등 시공 부위를 고르면 요즘 고객들이 가장 많이 선택하는 **스테디셀러 컬러 TOP 10**을 보여주고, 각 컬러마다 아래 내용을 제공하는 인테리어필름 컬러 상담 웹사이트입니다.

- **질감 확대 미리보기** — 무광/콘크리트/우드그레인/메탈/마블 질감을 실제 이보닥(ebodaq) 제품 이미지로 보여줍니다(불러오지 못하면 근사 색상 시뮬레이션으로 대체). "실사 이미지 참고" 버튼은 해당 제품코드로 검색된 이보닥 실제 제품 페이지로 바로 연결됩니다.
- **부위별 3D 시공 배치 시안(확대)** — 붙박이장/신발장(여닫이 도어 캐비닛), 싱크대(상부장+하부장 세트), 방문(단일 도어+손잡이), 중문(유리 격자 도어), 몰딩·걸레받이(방 모서리 벽면)처럼 실제 형태에 가까운 3D 목업에 실제 제품 이미지를 입혀 보여줍니다.
- **전문가 시공 Tip** — 질감별 공통 팁 + 시공 부위별 전문가 팁.
- **예상 견적 (실측 기반)** — ㎡(몰딩·걸레받이는 m) 단위로 사이즈를 입력하면 로스율·부자재비·배송비가 반영된 자재비와, 소요 시간/인력 기반 인건비가 자동으로 재계산됩니다. 방염 필름 여부를 선택할 수 있고, 각 금액을 클릭하면 상세 산출 근거를 펼쳐볼 수 있습니다. 브랜드별(현대L&C 보닥·LX하우시스·영림임업·예림임업) 시세 참고 표도 함께 제공합니다.
- **예상 견적서 (A4 인쇄/PDF)** — 선택한 컬러의 이미지, 3D 시공 시안, 시공 팁, 상세 견적 내역, 브랜드 시세 참고표를 담은 A4 규격 견적서를 열어 브라우저 인쇄 대화상자로 인쇄하거나 PDF로 저장할 수 있습니다.

인테리어필름 종류가 너무 많아 선택이 어려운 비전문가 고객이, 부담 없이 원하는 컬러/디자인 방향을 좁혀갈 수 있도록 돕는 상담 보조 도구입니다.

## 실행 방법

빌드 도구 없이 순수 HTML/CSS/JS로 만들어졌습니다. 저장소를 내려받은 뒤 `index.html`을 브라우저로 열거나, 로컬 서버로 띄워서 확인하세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 폴더 구조

```
index.html         메인 페이지
css/style.css       스타일 (파스텔 톤, 라이트/다크 테마 지원)
js/data.js          시공부위·컬러·제품코드·팁·견적 기준 데이터
js/app.js           화면 렌더링, 3D 목업 생성, 견적 계산 로직
```

## 데이터 업데이트

`js/data.js`의 `CATEGORIES`, `FILMS`, `TEXTURE_TIPS`, `CATEGORY_TIPS`, `BUDGET`, `BRAND_GUIDE` 값만 수정하면 시공 부위·컬러 목록·제품코드·팁·견적 기준·브랜드 시세표를 손쉽게 바꿀 수 있습니다. 부위별 3D 목업 형태(캐비닛 크기, 도어 수 등)는 `CATEGORIES[].mockup` 값으로, 방염 할증률·로스율 등 공통 계수는 `WASTE_RATE`/`ANCILLARY_RATE`/`FIRE_RETARDANT_MULTIPLIER`로 조절합니다.

## 데이터 출처와 실사 이미지 안내

제품명·제품코드(예: `LW116 Amber Oak`, `PNC47 Slate`)는 현대L&C "Bodaq Interior Film" 2026-2027 카탈로그의 실제 제품 정보를 바탕으로 합니다. 색상(hex)은 카탈로그 이미지를 참고해 화면 표현용으로 근사한 값이며, 실물과는 차이가 있을 수 있습니다(저작권이 있는 제품 사진 자체는 이 저장소에 포함하지 않았습니다).

"실사 이미지 참고" 팝업의 링크는 `js/data.js`의 `ebodaqLink(code)` 함수가 제품코드로 이보닥(ebodaq) 사이트를 검색하도록 만들어주므로, 각 컬러마다 실제로 일치하는 제품 페이지가 새 탭에서 열립니다.

## 견적 산출 방식과 출처

표준 필름 롤 규격(1,220mm × 50m)에 맞춰 "자(30cm)"가 아닌 **실측 면적(㎡)·길이(m)** 기준으로 계산합니다. 산출 공식은 `js/data.js`의 `BUDGET`에 정의되어 있습니다.

- **자재비** = 실측 수량 × (1 + 로스율 12%) × ㎡(m)당 단가 × 방염 배수(선택 시)
- **부자재비** = 자재비 × 10% (프라이머, 사포, 마스킹테이프, 커터날 등)
- **배송비** = 15,000원 (소량 주문 기준 정액)
- **인건비** = 실측 수량 × ㎡(m)당 인건비 단가 (부위별 소요시간·최소 출장비 반영)
- 방염 필름 선택 시 자재비에 1.5~2배 할증이 적용됩니다.

가격 기준(등급별 ㎡당 단가, 인건비, 로스율, 방염 할증률, 브랜드 시세)은 아래 자료를 조사해 종합한 참고치이며 실제 견적과 다를 수 있습니다.
